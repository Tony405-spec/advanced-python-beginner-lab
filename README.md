through to professional-grade Python engineering, with a Data Science
orientation.

This repository is my long-term learning environment. It is simultaneously:

- an Advanced Python course laboratory
- a revision and reference system
- a practical programming environment
- a Git/GitHub training ground

Every folder teaches a concept. Every commit represents real progress.
Every Pull Request is a genuine improvement — no filler, no artificial activity.

- **Python 3.x** — primary language
- **pytest** — testing
- **Ruff** — linting and formatting
- **mypy** — static type checking
- **pre-commit** — automated quality gates before commits

## Workflow

All changes follow a professional Git flow:

1. Branch from `main` with a descriptive name (`feature/...`, `fix/...`, `docs/...`).
2. Commit with conventional commit messages (`feat:`, `fix:`, `docs:`, `test:`).
3. Push the branch and open a Pull Request.
4. Review the diff, verify tests pass, merge into `main`.

Direct commits to `main` are avoided except for trivial maintenance.
