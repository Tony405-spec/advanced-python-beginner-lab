# Module 04 — Object-Oriented Programming

Classes, instances, methods, inheritance — and the Python-specific version
that differs from Java/C++/C#.

## Concepts covered

- **Class vs. instance** — class attributes vs. instance attributes.
- **`__init__` and `self`** — what `self` actually is.
- **Methods** — instance, class, static.
- **Inheritance** — single and multiple. Method resolution order (MRO).
- **`super()`** — cooperative multiple inheritance.
- **Composition over inheritance** — when to prefer has-a over is-a.
- **Dunder methods introduction** — `__repr__`, `__str__`, `__eq__` (deep dive in Module 16).

## Data Science connection

Every sklearn estimator and transformer is a class. Every PyTorch module is
a subclass of `nn.Module`. Custom losses, samplers, and callbacks are all
classes. A solid OOP foundation is non-negotiable for professional ML code.
