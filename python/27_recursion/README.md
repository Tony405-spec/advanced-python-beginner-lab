# Module 27 — Recursion & Algorithms

Recursion is a method of solving a problem where the solution depends on smaller instances of the same problem. This module covers the anatomy of recursive functions (base case + recursive step) using classic mathematical examples and algorithmic puzzles.

## Concepts covered
- Base case vs. Recursive step
- Deferred computation (call stack)
- Iterative vs. Recursive tradeoffs
- Divide and conquer (Fast Power)

## Data Science connection
Recursive tree traversal is the foundation for decision trees and random forests. Understanding the call stack is also critical for debugging deep neural network algorithms.
